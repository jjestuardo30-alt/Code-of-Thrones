# ⚔️ Code of Thrones

Simulador de combate por turnos desarrollado en Java como práctica de 
Programación Orientada a Objetos (POO).

---

## 📖 Descripción

El proyecto simula batallas entre personajes de fantasía (Guerrero, Mago y Monstruo).
Cada personaje tiene atributos, habilidades únicas y cartas especiales que puede usar 
en combate. Desarrollado para practicar herencia, interfaces, clases abstractas y enums en Java.

---

## ⚙️ Funcionalidades

- Personajes con atributos: nombre, nivel, puntos de vida
- Sistema de daño y defensa por personaje
- Cartas especiales únicas por clase (ej: Furia Berserker, Bola de Fuego, Rugido Atronador)
- Sistema de rareza de cartas con enum (Común, Rara, Épica, Leyenda)
- Límites de vida (0 - 1000) con mensajes de estado

---

## 🧱 Contexto

Proyecto desarrollado en clase de **Programación en Java** (DAM - La Salle Gràcia).
El objetivo era aplicar los conceptos de POO: herencia, polimorfismo, interfaces y enums.
